# Standalone website scope

Blinto Performance currently runs as a standalone framework website.

## Included

- KPI and scoring framework
- Career framework and department ladders
- Role Success Plans
- Review process and 2027 leveling timeline
- Team framework roster

## Intentionally deferred

- HRMS authentication
- Employee account sessions
- HRMS user-directory integration
- HRMS KPI/review API integration

These integrations can be added later without changing the current Markdown source-of-truth model.
