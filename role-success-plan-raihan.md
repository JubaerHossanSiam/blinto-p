# Role Success Plan — Raihan

## Role

**Frontend Developer**

**Core department:** Engineering  
**Career level:** To be confirmed

## Role purpose

Build reliable frontend experiences from approved designs and requirements while maintaining strong implementation quality, responsive behavior, and dependable delivery.

## Core success outcomes

1. **Implementation accuracy** — frontend work matches approved design, content, and functional requirements.
2. **Responsive quality** — interfaces work correctly across expected breakpoints, devices, and supported browsers.
3. **Code quality** — implementation is maintainable, appropriately reusable, and aligned with team standards.
4. **Self-QA** — visual, interaction, content, and regression issues are checked before review or handoff.
5. **Delivery discipline** — progress, blockers, dependencies, and realistic timing are communicated early.
6. **Continuous improvement** — feedback is applied consistently so repeated defects decrease and independence increases.

## Observable evidence

Evidence may include implementation accuracy, low preventable rework, responsive and browser quality, code review feedback, successful releases, task reliability, and visible improvement after feedback.

## Role Excellence standard

**Exceptional** performance means Raihan consistently produces polished work, identifies issues before review, handles increasingly complex work independently, and contributes improvements beyond assigned implementation.

**Effective** performance means assigned frontend work meets requirements, passes expected quality checks, is delivered reliably, and review feedback is incorporated into future work.

**Needs Improvement** applies when preventable defects recur, testing is weak, rework remains high, blockers are surfaced late, or the same feedback must repeatedly be given.

## Monthly Role Excellence review

Role Excellence should be scored from documented monthly evidence against the outcomes above, not from general impressions. The universal five-level rating scale in the KPI framework applies.
