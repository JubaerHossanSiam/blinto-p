# Engineering Career Ladder

| Level | Designation |
|---|---|
| L1 | Associate Engineer |
| L2 | Engineer |
| L3 | Senior Engineer |
| L4 | Lead Engineer |
| L5 | Principal Engineer / Engineering Manager |
| L6 | Engineering Architect / Head of Engineering |
| L7 | Engineering Director |

Engineering Role Excellence should be assessed against the employee's specific Role Success Plan.

Typical evidence includes engineering quality, technical problem solving, ownership, reliability, maintainability, professional delivery, and increasing independence.
