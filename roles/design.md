# Design Career Ladder

| Level | Designation |
|---|---|
| L1 | Associate Designer |
| L2 | Designer |
| L3 | Senior Designer |
| L4 | Lead Designer |
| L5 | Principal Designer / Design Manager |
| L6 | Design Architect / Head of Design |
| L7 | Creative Director / Design Director |

Role Excellence should reflect design quality, UX thinking, conversion awareness, developer handoff, design systems, client feedback, and effective use of AI-assisted design workflows.
